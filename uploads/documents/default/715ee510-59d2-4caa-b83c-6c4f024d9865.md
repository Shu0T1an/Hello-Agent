# CLAUDE.md

本文件为 Claude Code (claude.ai/code) 在此仓库中工作提供指导。

## 项目概述

本项目是哈尔滨工程大学的**工学硕士学位论文**，题目为**"基于无人机视角的目标检测与跟踪算法研究"** (Research on Target Detection and Tracking Algorithms Based on UAV Perspective)。

## 仓库结构

- `毕业论文.md` - 论文主文档（Markdown格式）
- `media/` - 论文中引用的图片资源
- `.docx` 文件 - Word文档版本（二进制文件，编辑时忽略）

## 论文结构

论文遵循标准学术论文格式：
- 封面（分类号、密级等）
- 原创性声明与授权声明
- 摘要（中英文）及关键词
- 目录
- 第1章：绪论（研究背景、意义、国内外研究现状）
- 第2章：相关理论和技术基础（深度学习、CNN、目标检测、跟踪）
- 第3-5章：改进方法（改进检测、轻量化模型、跟踪算法）
- 第6章：实验与结果分析
- 第7章：结论与展望
- 参考文献

## 在此仓库工作

### 写作与编辑规范

- **论文内容使用中文** - 论文主体为中文，摘要有英文版本
- **遵循标准Markdown学术格式** - 使用 `#` 表示章，`##` 表示节，`###` 表示小节
- **图片引用格式**：使用 `![图X-Y 描述](media/imageN.png)`
- **公式格式**：使用LaTeX语法 `$$ ... $$`，编号格式如 `式(2-1)`
- **参考文献格式**：使用 `[数字]` 格式，如 `[16]`

### Git 工作流程

```bash
# 提交论文修改，附上描述性信息
git add 毕业论文.md
git commit -m "描述本次修改内容"

# 推送到远程仓库（如果已配置）
git push
```

### 忽略二进制文件

`.docx` 文件是Word文档（二进制格式），编辑时应忽略，只需编辑 Markdown 版本 (`毕业论文.md`)。
